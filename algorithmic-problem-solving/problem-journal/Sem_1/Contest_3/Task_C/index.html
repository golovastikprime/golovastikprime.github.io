Задача C — Знакочередующаяся сумма

Accepted · C++ · 2 августа 2026

Ответ отрезка дополняется чётностью его длины, чтобы соседние части можно было склеивать в правильном порядке.

Результат

Статус

Accepted. Segment Tree построен над ассоциативной, но некоммутативной операцией.

  • построение: \(O(n)\);
  • присваивание и запрос: \(O(\log n)\);
  • память: \(O(n)\).

Условие

Два типа запросов

Для массива \(a_1,a_2,\ldots,a_n\) нужно онлайн выполнять:

  • 0 i x — присвоить \(a_i=x\);
  • 1 l r — вычислить \(a_l-a_{l+1}+a_{l+2}-\cdots+(-1)^{r-l}a_r\).

Первый элемент каждого запрошенного диапазона всегда берётся со знаком «плюс» независимо от его глобального индекса.

Ключевое наблюдение

Сумма и чётность длины

Для последовательности \(X=(x_1,\ldots,x_k)\) определим

\[ S(X)=x_1-x_2+x_3-\cdots+(-1)^{k-1}x_k. \]

Одной суммы недостаточно: знак первой позиции следующей части зависит от длины левой. Поэтому состояние равно

\[ M(X)=\bigl(S(X),|X|\bmod2\bigr). \]

В коде value хранит сумму, а is_even — чётность длины.

Операция

Конкатенация состояний

Если \(X\) расположен перед \(Y\), то

\[ S(X\|Y)=S(X)+(-1)^{|X|}S(Y). \]

При чётной длине левой части правая сумма прибавляется, при нечётной — вычитается. Суммарная длина чётна тогда и только тогда, когда чётности частей совпадают.

AlternatingSum operator*(const AlternatingSum& rhs) const {
  bool new_is_even = (is_even == rhs.is_even);
  if (is_even) return {value + rhs.value, new_is_even};
  return {value - rhs.value, new_is_even};
}

Порядок важен

Операция некоммутативна

Для одноэлементных частей \((5)*(2)=3\), но \((2)*(5)=-3\). Поэтому внутренний узел всегда строится как левый сын, затем правый:

tree_[v] = tree_[2 * v] * tree_[2 * v + 1];

Перестановка сыновей меняет ответ.

Нейтральный элемент

Пустая последовательность

Пустая последовательность имеет сумму ноль и чётную длину:

static AlternatingSum Identity() { return {0, true}; }
static AlternatingSum Leaf(long long value) { return {value, false}; }

Дополнительные листья также нейтральны и семантически представляют пустые последовательности.

Моноид

Почему операция ассоциативна

Для состояний \(A=(s,p),B=(t,q),C=(u,r)\) обе расстановки скобок дают значение

\[ s+(-1)^p t+(-1)^{p\oplus q}u \]

и чётность \(p\oplus q\oplus r\), поскольку

\[ (-1)^{p\oplus q}=(-1)^p(-1)^q. \]

Вместе с нейтральным элементом это образует моноид, пригодный для Segment Tree.

Запрос

Два аккумулятора

Один аккумулятор безопасен только для коммутативной операции. Здесь левая и правая части собираются отдельно:

Monoid left_answer = Monoid::Identity();
Monoid right_answer = Monoid::Identity();

if ((left & 1) != 0) {
  left_answer = left_answer * tree_[left++];
}
if ((right & 1) == 0) {
  right_answer = tree_[right--] * right_answer;
}

return left_answer * right_answer;

Новый правый узел ставится перед уже собранной правой частью. Обратный порядок дал бы неверную последовательность.

Доказательство

Корректность дерева

Слияние. Если левая длина чётна, знаки правой части сохраняются; если нечётна — меняются на противоположные. Это в точности реализует operator*.

Узлы. Листья корректны, а внутренний узел описывает конкатенацию левого и правого диапазонов.

Присваивание. Меняется один лист и его предки, поэтому все остальные диапазоны остаются корректными.

Запрос. Два аккумулятора сохраняют геометрический порядок канонических отрезков. После их объединения поле value равно требуемой сумме.

Реализация

Итоговый код

#include <iostream>
#include <vector>

template <typename Monoid>
class SegmentTree {
 public:
  explicit SegmentTree(const std::vector<Monoid>& nums) {
    while (N_ < static_cast<int>(nums.size())) N_ *= 2;
    tree_.assign(2 * N_, Monoid::Identity());
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
      tree_[N_ + i] = nums[i];
    }
    for (int v = N_ - 1; v >= 1; --v) {
      tree_[v] = tree_[2 * v] * tree_[2 * v + 1];
    }
  }

  Monoid RangeOperation(int left, int right) const {
    left += N_;
    right += N_;
    Monoid left_answer = Monoid::Identity();
    Monoid right_answer = Monoid::Identity();
    while (left <= right) {
      if ((left & 1) != 0) left_answer = left_answer * tree_[left++];
      if ((right & 1) == 0) right_answer = tree_[right--] * right_answer;
      left >>= 1;
      right >>= 1;
    }
    return left_answer * right_answer;
  }

  void Assign(int index, const Monoid& value) {
    int v = index + N_;
    tree_[v] = value;
    while (v > 1) {
      v >>= 1;
      tree_[v] = tree_[2 * v] * tree_[2 * v + 1];
    }
  }

 private:
  std::vector<Monoid> tree_;
  int N_{1};
};

struct AlternatingSum {
  long long value{0};
  bool is_even{true};

  static AlternatingSum Leaf(long long value) { return {value, false}; }
  static AlternatingSum Identity() { return {0, true}; }

  AlternatingSum operator*(const AlternatingSum& rhs) const {
    bool new_is_even = (is_even == rhs.is_even);
    return is_even ? AlternatingSum{value + rhs.value, new_is_even}
                   : AlternatingSum{value - rhs.value, new_is_even};
  }
};

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  int n;
  std::cin >> n;
  std::vector<AlternatingSum> arr(n);
  for (int i = 0; i < n; ++i) {
    long long value;
    std::cin >> value;
    arr[i] = AlternatingSum::Leaf(value);
  }
  SegmentTree<AlternatingSum> segment_tree(arr);
  int query_count;
  std::cin >> query_count;
  while (query_count-- > 0) {
    int command, first;
    long long second;
    std::cin >> command >> first >> second;
    --first;
    if (command == 0) {
      segment_tree.Assign(first, AlternatingSum::Leaf(second));
    } else {
      std::cout << segment_tree.RangeOperation(
          first, static_cast<int>(second) - 1).value << '\n';
    }
  }
}

Самопроверка

Ошибки и граничные случаи

  • is_even описывает длину отрезка, а не его левую границу;
  • лист нечётный, нейтральный пустой отрезок чётный;
  • правый аккумулятор собирается выражением tree_[right] * right_answer;
  • запрос из одного элемента возвращает сам элемент;
  • дополнительные листья нейтральны;
  • long long защищает сумму от переполнения.

Альтернатива

Глобальные знаки и обычная сумма

Можно определить \(b_i=(-1)^{i-1}a_i\) и хранить обычные суммы в Fenwick Tree или Segment Tree. Сумма \([l,r]\) меняет знак, если \(l\) чётно. Моноидный вариант ценен тем, что состояние отрезка не зависит от абсолютной позиции и демонстрирует общий шаблон некоммутативных запросов.

Обобщение

Как распознать паттерн

Если ответ объединения зависит от длины, чётности или граничного состояния части, следует дополнить значение минимальной метаинформацией, достаточной для склейки, а затем доказать ассоциативность и найти нейтральный элемент.

Знак правой суммы определяется чётностью левой части. Операция ассоциативна, но порядок частей менять нельзя.
