Семестр 1 · Контест 3

Задача A — Вторая статистика

Accepted · C++ · 2 августа 2026

В каждом узле Segment Tree достаточно хранить два минимальных элемента — с учётом повторений.

Результат

Статус

Accepted. Неизменяемый массив обрабатывается деревом отрезков с компактным состоянием из двух минимумов.

  • построение: \(O(n)\);
  • один запрос: \(O(\log n)\);
  • память: \(O(n)\).

Условие

Второй элемент после сортировки

Дан неизменяемый массив \(a_1,a_2,\ldots,a_n\). Для каждого включительного отрезка \([l,r]\) нужно найти второй элемент мультимножества

\[ \{a_l,a_{l+1},\ldots,a_r\} \]

после сортировки по неубыванию. Повторения учитываются: для [1, 1, 5] ответ равен 1, а не 5. По условию \(l<r\), поэтому элементов всегда хотя бы два.

Ключевое наблюдение

Два минимума на узел

Чтобы найти два наименьших элемента объединения, достаточно знать два наименьших элемента каждой части. Узел хранит пару

\[ (m_1,m_2), \qquad m_1\le m_2, \]

где \(m_1\) — минимум, а \(m_2\) — второй минимум с учётом повторений. Одного минимума недостаточно: отрезки [1, 1] и [1, 100] имели бы одинаковое состояние.

Моноид

Слияние двух пар

Пусть \(L=(l_1,l_2)\) и \(R=(r_1,r_2)\). Если \(l_1\le r_1\), общий минимум равен \(l_1\), а вторым может быть только \(l_2\) или \(r_1\):

\[ \operatorname{Merge}(L,R)=\bigl(l_1,\min(l_2,r_1)\bigr). \]

В противоположном случае формула симметрична.

static Item Merge(const Item& first, const Item& second) {
  if (first.first <= second.first) {
    return {first.first, std::min(first.second, second.first)};
  }
  return {second.first, std::min(first.first, second.second)};
}

Знак равенства важен: \(\operatorname{Merge}((1,\infty),(1,\infty))=(1,1)\).

Нейтральный элемент

Пустой отрезок

Пустой диапазон описывается парой \(e=(+\infty,+\infty)\), поэтому

\[ \operatorname{Merge}(X,e)=\operatorname{Merge}(e,X)=X. \]

В коде используется INT_MAX. Это безопасно при \(|a_i|\le10^9<\texttt{INT\_MAX}\).

Построение

Листья и внутренние узлы

Основание N_ — ближайшая степень двойки, не меньшая \(n\). Настоящий лист хранит \((a_i,+\infty)\), дополнительный лист — нейтральную пару, а внутренний узел получается слиянием сыновей.

Запрос

Итеративное разбиение диапазона

После перехода к листьям поддерживаются включительные границы l и r. Правый сын на левой границе и левый сын на правой границе целиком добавляются в аккумулятор, после чего указатели поднимаются к родителям.

Item ans = {INT_MAX, INT_MAX};
while (l <= r) {
  if ((l & 1) != 0) ans = Merge(ans, tree_[l++]);
  if ((r & 1) == 0) ans = Merge(ans, tree_[r--]);
  l >>= 1;
  r >>= 1;
}
return ans.second;

Доказательство

Почему ответ корректен

Слияние. Если минимум объединения пришёл из левой части, после удаления одного его экземпляра минимальными кандидатами остаются второй элемент слева и первый справа. Симметрично для правой части.

Дерево. Листья корректны по определению. Если оба сына хранят два минимума своих отрезков, Merge даёт два минимума их непересекающегося объединения.

Запрос. Выбранные канонические узлы попарно не пересекаются и точно покрывают исходный диапазон. Аккумулятор после каждого шага содержит два минимума их объединения, поэтому в конце ans.second — требуемая статистика.

Порядок вычислений

Ассоциативность

Merge семантически берёт два минимума объединения мультимножеств, поэтому операция ассоциативна. В этой задаче она также коммутативна, и канонические отрезки можно объединять в любом порядке.

Оценка

Сложность и ограничение подхода

Для ближайшей степени двойки \(N<2n\). Построение занимает \(O(n)\), запрос — \(O(\log n)\), все запросы — \(O(n+q\log n)\), память — \(O(n)\).

В условии рекомендована Sparse Table с ответом за \(O(1)\). Принятая реализация прошла тесты, но её честная оценка остаётся \(O(\log n)\). Для строгого \(O(1)\) подходит, например, Disjoint Sparse Table; обычные перекрывающиеся блоки могут дважды учесть одну позицию.

Реализация

Принятый код

#include <algorithm>
#include <climits>
#include <iostream>
#include <utility>
#include <vector>

class SegmentTree {
  using Item = std::pair<int, int>;

  static Item Merge(const Item& first, const Item& second) {
    if (first.first <= second.first) {
      return {first.first, std::min(first.second, second.first)};
    }
    return {second.first, std::min(first.first, second.second)};
  }

 public:
  explicit SegmentTree(const std::vector<int>& nums) {
    std::size_t size = 1;
    while (size < nums.size()) size *= 2;
    N_ = size;
    tree_.assign(2 * N_, {INT_MAX, INT_MAX});
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
      tree_[N_ + i] = {nums[i], INT_MAX};
    }
    for (int v = static_cast<int>(N_) - 1; v >= 1; --v) {
      tree_[v] = Merge(tree_[2 * v], tree_[2 * v + 1]);
    }
  }

  int Range2Stat(int l, int r) const {
    l += static_cast<int>(N_);
    r += static_cast<int>(N_);
    Item ans = {INT_MAX, INT_MAX};
    while (l <= r) {
      if ((l & 1) != 0) ans = Merge(ans, tree_[l++]);
      if ((r & 1) == 0) ans = Merge(ans, tree_[r--]);
      l >>= 1;
      r >>= 1;
    }
    return ans.second;
  }

 private:
  std::vector<Item> tree_;
  std::size_t N_;
};

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  int n, q;
  std::cin >> n >> q;
  std::vector<int> nums(n);
  for (int& value : nums) std::cin >> value;
  SegmentTree st(nums);
  while (q-- > 0) {
    int l, r;
    std::cin >> l >> r;
    std::cout << st.Range2Stat(l - 1, r - 1) << '\n';
  }
}

Самопроверка

Граничные случаи и ошибки

  • [5, 5] даёт 5: ищется не второй различный элемент;
  • для листа второй минимум равен бесконечности;
  • диапазон в Range2Stat включительный с обеих сторон;
  • входные индексы переводятся из нумерации с единицы в нумерацию с нуля;
  • дополнительные листья нейтральны, если размер массива не является степенью двойки;
  • <algorithm> и <utility> подключаются явно.

Обобщение

Как распознать паттерн

Segment Tree подходит, когда много запросов на отрезках, ответ объединения вычисляется из компактных ответов частей, а операция слияния ассоциативна. Для малого фиксированного \(k\) можно хранить в каждом узле \(k\) минимумов и сливать два отсортированных списка за \(O(k)\).

Храним два минимума. Меньший из первых становится общим минимумом, а второй выбирается между следующим элементом той же части и минимумом другой части.
