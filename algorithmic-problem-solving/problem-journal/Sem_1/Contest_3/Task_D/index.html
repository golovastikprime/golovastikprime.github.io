Семестр 1 · Контест 3

Задача D — Ближайший больший

Accepted · C++ · 2 августа 2026

Максимум сегмента отвечает, может ли внутри существовать кандидат, а обход слева направо находит первый допустимый индекс.

Результат

Статус

Accepted. Использован Segment Tree по максимуму с точечным присваиванием и поиском первого подходящего листа.

  • построение: \(O(n)\);
  • присваивание и поиск: \(O(\log n)\);
  • память: \(O(n)\).

Условие

Первый элемент не меньше порога

Для массива \(a_1,\ldots,a_n\) нужно онлайн выполнять:

  • 0 i x — присвоить \(a_i=x\);
  • 1 i x — найти минимальный \(j\ge i\), для которого \(a_j\ge x\).

Если ответа нет, выводится -1. Ограничения: \(n,q\le2\cdot10^5\).

Ключевое наблюдение

Максимум как проверка существования

Для сегмента \([l,r)\) храним

\[ M([l,r))=\max_{l\le k<r}a_k. \]

Если \(M<x\), кандидата внутри нет и весь сегмент можно отбросить. Если \(M\ge x\), хотя бы один кандидат существует, и поиск продолжает спуск.

Моноид

Максимум и нейтральный элемент

Операция объединения — \(u*v=\max(u,v)\). Она ассоциативна, а нейтральным элементом служит \(-\infty\), представленный как INT_MIN.

Дополнительные листья получают INT_MIN, поэтому не меняют максимум и не могут стать ответом при допустимом \(x\ge0\).

Состояние дерева

Инвариант

\[ \texttt{tree[v]}=\max_{l\le k<r}a_k \]

для каждой вершины, соответствующей \([l,r)\). Листья корректны по определению, внутренние вершины берут максимум детей. После присваивания пересчитывается только путь изменённого листа к корню.

Спуск

Три случая поиска

FindFirstImpl(v, left, right, i, x) ищет первый ответ в пересечении \([left,right)\cap[i,n)\).

  1. Если right <= i, сегмент целиком левее начала поиска.
  2. Если tree_[v] < x, ни один элемент сегмента не достигает порога.
  3. Если неотброшенный сегмент является листом, его левый конец — допустимый ответ.
if (right <= index || tree_[v] < value) return -1;
if (right - left == 1) return left;

Минимальный индекс

Почему сначала левый ребёнок

Все индексы левого ребёнка меньше индексов правого. Поэтому алгоритм сначала ищет слева и переходит направо, только если слева ответа нет:

int answer = FindFirstImpl(2 * v, left, middle, index, value);
if (answer != -1) return answer;
return FindFirstImpl(2 * v + 1, middle, right, index, value);

Так первый найденный лист имеет минимальный допустимый индекс.

Доказательство

Корректность поиска

Сегмент левее \(i\) не содержит допустимых индексов. Сегмент с максимумом меньше \(x\) не содержит подходящих значений. Неотброшенный лист удовлетворяет обоим требованиям. Для внутреннего узла рекурсия возвращает минимальный ответ левого ребёнка, а при его отсутствии — минимальный ответ правого. По индукции это даёт минимальный ответ всего дерева либо -1.

Оценка

Почему поиск логарифмический

Поиск не обходит дерево целиком: сегменты без кандидата отбрасываются по максимуму, а сегменты левее начала — по границе. Суффикс можно представить как \(O(\log n)\) канонических сегментов, после чего выполняется один спуск к листу. Итого обработка всех запросов занимает \(O(n+q\log n)\).

Реализация

Принятый код

#include <algorithm>
#include <climits>
#include <iostream>
#include <vector>

template <typename Monoid>
class SegmentTree {
 public:
  explicit SegmentTree(const std::vector<Monoid>& nums) {
    while (N_ < nums.size()) N_ *= 2;
    tree_.assign(2 * N_, Monoid::Identity());
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
      tree_[N_ + i] = nums[i];
    }
    for (int v = static_cast<int>(N_) - 1; v >= 1; --v) {
      tree_[v] = tree_[2 * v] * tree_[2 * v + 1];
    }
  }

  int FindFirst(int index, int value) const {
    return FindFirstImpl(1, 0, static_cast<int>(N_), index, value);
  }

  void Assign(int index, Monoid value) {
    int v = index + static_cast<int>(N_);
    tree_[v] = value;
    while (v > 1) {
      v >>= 1;
      tree_[v] = tree_[2 * v] * tree_[2 * v + 1];
    }
  }

 private:
  int FindFirstImpl(int v, int left, int right,
                    int index, int value) const {
    if (right <= index || tree_[v] < value) return -1;
    if (right - left == 1) return left;
    int middle = left + (right - left) / 2;
    int answer = FindFirstImpl(2 * v, left, middle, index, value);
    if (answer != -1) return answer;
    return FindFirstImpl(2 * v + 1, middle, right, index, value);
  }

  std::vector<Monoid> tree_;
  std::size_t N_{1};
};

struct Monoid {
  int value{INT_MIN};
  Monoid() = default;
  Monoid(int value) : value(value) {}
  static Monoid Identity() { return Monoid(INT_MIN); }
  Monoid operator*(const Monoid& rhs) const {
    return Monoid(std::max(value, rhs.value));
  }
  bool operator<(int rhs) const { return value < rhs; }
};

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  int n, q;
  std::cin >> n >> q;
  std::vector<Monoid> array(n);
  for (Monoid& item : array) std::cin >> item.value;
  SegmentTree<Monoid> segment_tree(array);
  while (q-- > 0) {
    int command, index, value;
    std::cin >> command >> index >> value;
    --index;
    if (command == 0) {
      segment_tree.Assign(index, value);
    } else {
      int answer = segment_tree.FindFirst(index, value);
      std::cout << (answer == -1 ? -1 : answer + 1) << '\n';
    }
  }
}

Самопроверка

Граничные случаи

  • сама позиция \(i\) входит в область поиска;
  • при отсутствии ответа возвращается -1;
  • условие допускает равенство, поэтому сегмент отбрасывается при maximum < x, не при <=;
  • после присваивания пересчитываются все предки до корня;
  • входной индекс уменьшается на один, найденный при выводе увеличивается.

Обобщение

Segment Tree как поисковая структура

Если агрегат узла отвечает на вопрос «может ли здесь быть ответ?», дерево может не только вычислять значение диапазона, но и искать позицию. Для условия >= x подходит максимум, для <= x — минимум, для заданной префиксной суммы при неотрицательных элементах — сумма.

Отбрасываем сегменты без кандидата и всегда проверяем левую часть раньше правой, чтобы получить первый индекс.
