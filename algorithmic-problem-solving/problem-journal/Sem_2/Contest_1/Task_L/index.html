Задача L — Чередующаяся подпоследовательность

Accepted · C++ · 28 июля 2026

Направление последнего шага становится частью состояния DP, а сохранённые предки позволяют восстановить одну максимальную лесенку.

Результат

Статус

Accepted. Решение использует два состояния по последнему элементу и восстанавливает одну оптимальную подпоследовательность.

  • время: \(\Theta(n^2)\);
  • память: \(\Theta(n)\);
  • восстановление: \(O(k)\).

Условие

Математическая формулировка

Дана последовательность

\[ a_1,a_2,\ldots,a_n, \qquad 1\le n\le2000. \]

Нужно выбрать подпоследовательность с возрастающими индексами, в которой направления соседних шагов чередуются:

\[ a_{i_1}<a_{i_2}>a_{i_3}<a_{i_4}>\ldots \]

или

\[ a_{i_1}>a_{i_2}<a_{i_3}>a_{i_4}<\ldots. \]

Эквивалентное условие для каждого внутреннего элемента:

\[ \bigl(a_{i_t}-a_{i_{t-1}}\bigr) \bigl(a_{i_{t+1}}-a_{i_t}\bigr)<0. \]

Требуется вывести максимальную длину и одну подпоследовательность этой длины. Равные соседние значения использовать нельзя: между ними нет шага вверх или вниз.

Ограничения

Почему допустим перебор пар

При \(n\le2000\) можно перебрать все пары индексов \(j<i\):

\[ \sum_{i=1}^{n}(i-1) = \frac{n(n-1)}2 = \Theta(n^2). \]

Естественно зафиксировать последний индекс \(i\), перебрать предпоследний \(j\) и использовать ответы для уже обработанного префикса.

Наблюдение

Нужно помнить направление шага

Одной максимальной длины подпоследовательности, оканчивающейся в \(a_i\), недостаточно: возможность добавить следующий элемент зависит от последнего направления.

Если \(a_j<a_i\), новый шаг направлен вверх, поэтому предыдущий должен быть направлен вниз:

\[ \ldots>a_j<a_i. \]

Симметрично, шаг вниз разрешён только после шага вверх:

\[ \ldots<a_j>a_i. \]

На каждом переходе тип состояния меняется:

\[ \mathrm{down}\longrightarrow\mathrm{up}, \qquad \mathrm{up}\longrightarrow\mathrm{down}. \]

Динамика

Состояния и переходы

Для каждого индекса \(i\) определим:

  • \(up[i]\) — максимальная длина лесенки, оканчивающейся в \(a_i\) шагом вверх;
  • \(down[i]\) — максимальная длина лесенки, оканчивающейся в \(a_i\) шагом вниз.

Одноэлементная подпоследовательность не имеет направления, поэтому для удобства представляется обоими состояниями:

\[ up[i]=down[i]=1. \]

Переход вверх

\[ \boxed{ up[i] = 1+\max_{\substack{j<i\\a_j<a_i}}down[j] }. \]

Переход вниз

\[ \boxed{ down[i] = 1+\max_{\substack{j<i\\a_j>a_i}}up[j] }. \]

Принимается соглашение \(\max\varnothing=0\). Равенство \(a_j=a_i\) не создаёт перехода.

Вычисление

Порядок и инвариант

Индексы обрабатываются слева направо. Перед обработкой \(i\) значения \(up[j]\) и \(down[j]\) для всех \(j<i\) уже равны оптимальным длинам соответствующих типов.

Переходы перебирают все возможные предпоследние индексы и выбирают лучший допустимый. После этого инвариант становится верным и для \(i\).

Доказательство

Корректность перехода

Докажем формулу для \(up[i]\); вторая доказывается симметрично. Обозначим

\[ M= \max_{\substack{j<i\\a_j<a_i}}down[j]. \]

Верхняя оценка

Удалим \(a_i\) из оптимальной лесенки состояния \(up[i]\). Если её длина больше одного, остаток оканчивается в некотором \(a_j<a_i\) состоянием \(down[j]\). Значит,

\[ up[i]-1\le down[j]\le M, \qquad up[i]\le M+1. \]

Нижняя оценка

Возьмём индекс \(j\), на котором достигается \(M\), и добавим \(a_i\) к соответствующей лесенке. Новый шаг идёт вверх, предыдущий — вниз, поэтому чередование сохраняется и получается длина \(M+1\).

При отсутствии подходящего \(j\) остаётся одноэлементная лесенка. Следовательно,

\[ up[i]=M+1. \]

По индукции по \(i\) все состояния вычисляются корректно.

Ответ

Финальное состояние

Оптимальная лесенка может оканчиваться в любом индексе и любым направлением:

\[ \boxed{ \operatorname{Answer} = \max_{0\le i<n}\max\bigl(up[i],down[i]\bigr) }. \]

После заполнения DP программа запоминает максимальную длину, последний индекс и тип последнего состояния.

Восстановление

Указатели на предков

Вместе с длинами хранятся:

  • parent_up[i] — предпоследний индекс для состояния \(up[i]\);
  • parent_down[i] — предпоследний индекс для состояния \(down[i]\).

Значение -1 означает одноэлементную лесенку. Во время обратного прохода состояние однозначно задаёт нужный массив:

\[ (i,\mathrm{up}) \longrightarrow (parent\_up[i],\mathrm{down}), \]
\[ (i,\mathrm{down}) \longrightarrow (parent\_down[i],\mathrm{up}). \]

Тип предка хранить отдельно не нужно: он всегда противоположен текущему. Индекс при каждом шаге строго уменьшается, а длина состояния уменьшается на единицу. Полученная цепочка идёт справа налево, поэтому перед выводом её разворачивают.

Пример

Восстановление лесенки

Для последовательности

\[ 1,\ 7,\ 4,\ 9,\ 2,\ 5 \]

максимальное состояние равно \(up[5]=6\). Цепочка предков:

\[ (5,\mathrm{up}) \to (4,\mathrm{down}) \to (3,\mathrm{up}) \to (2,\mathrm{down}) \to (1,\mathrm{up}) \to (0,\mathrm{down}). \]

После разворота:

\[ 1<7>4<9>2<5. \]

Реализация

Accepted-код

#include <algorithm>
#include <iostream>
#include <vector>

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  std::cout.tie(nullptr);

  int n;
  std::cin >> n;

  std::vector<int> arr(n);
  for (int i = 0; i < n; ++i) {
    std::cin >> arr[i];
  }

  std::vector<int> parent_up(n, -1);
  std::vector<int> parent_down(n, -1);
  std::vector<int> down(n, 1);
  std::vector<int> up(n, 1);

  for (int i = 0; i < n; ++i) {
    int max_for_down = 0;
    int max_for_up = 0;

    for (int j = 0; j < i; ++j) {
      if (arr[j] < arr[i] && max_for_up < down[j]) {
        parent_up[i] = j;
        max_for_up = down[j];
      }

      if (arr[j] > arr[i] && max_for_down < up[j]) {
        parent_down[i] = j;
        max_for_down = up[j];
      }
    }

    down[i] = 1 + max_for_down;
    up[i] = 1 + max_for_up;
  }

  int ans = 0;
  int current_idx = 0;
  bool was_up = false;

  for (int i = 0; i < n; ++i) {
    if (down[i] > ans) {
      current_idx = i;
      was_up = false;
      ans = down[i];
    }

    if (up[i] > ans) {
      current_idx = i;
      was_up = true;
      ans = up[i];
    }
  }

  std::vector<int> answer;
  answer.reserve(ans);

  while (current_idx != -1) {
    answer.push_back(arr[current_idx]);

    if (was_up) {
      current_idx = parent_up[current_idx];
    } else {
      current_idx = parent_down[current_idx];
    }

    was_up = !was_up;
  }

  std::cout << ans << '\n';

  for (int i = ans - 1; i >= 0; --i) {
    std::cout << answer[i] << ' ';
  }
}

Оценка

Сложность

Для каждого \(i\) перебираются все \(j<i\):

\[ \sum_{i=0}^{n-1}i = \frac{n(n-1)}2 = \Theta(n^2). \]

Поиск финального состояния занимает \(O(n)\), восстановление — \(O(k)\), поэтому

\[ \boxed{T(n)=\Theta(n^2)}. \]

Все массивы имеют линейный размер:

\[ \boxed{W(n)=\Theta(n)}. \]

Разбор ошибок

Ошибки и тупики

  1. Независимые up и down. Продолжение подъёма подъёмом нарушает чередование. Верная связь: \(\mathrm{down}\to\mathrm{up}\) и \(\mathrm{up}\to\mathrm{down}\).
  2. Не зафиксирован последний индекс. Для подпоследовательности важно, каким элементом она оканчивается; после фиксации \(i\) появляется естественный перебор \(j<i\).
  3. Нулевая база. Один элемент уже образует лесенку длины один, поэтому \(up[i]=down[i]=1\).
  4. Повторный перебор перехода. Лишний цикл заново просматривал все \(j<i\) и превращал алгоритм в \(\Theta(n^3)\).
  5. Раннее переключение состояния. Из состояния up сначала нужно перейти по parent_up и только затем сменить тип на down.
  6. Обращение к arr[-1]. К текущему элементу можно обращаться только после проверки current_idx != -1.
  7. Только одна оценка в доказательстве. Удаление последнего элемента даёт верхнюю оценку; для равенства нужно также взять состояние, достигающее максимума, и доказать возможность добавить \(a_i\).

Перенос идеи

Как распознать паттерн

  • строится подпоследовательность с возрастающими индексами;
  • естественно зафиксировать последний выбранный индекс;
  • переход перебирает предпоследний индекс;
  • для продолжения нужна небольшая часть истории — здесь направление последнего шага;
  • нужно вывести объект, поэтому вместе с DP хранятся предки;
  • ограничение \(n\le2000\) допускает перебор пар.
\[ \text{подпоследовательность} \Longrightarrow \text{последний индекс} \Longrightarrow \text{тип последнего шага} \Longrightarrow \text{перебор }j<i \Longrightarrow \text{предок}. \]

Вывод

Главный итог

Состояния только по последнему индексу недостаточно. Нужно хранить ровно ту часть прошлого, от которой зависит следующий переход — направление последнего шага:

\[ up[i]\leftrightarrow down[j]. \]

Такое разбиение даёт корректное DP за \(\Theta(n^2)\), а сохранение лучшего предка восстанавливает оптимальную лесенку за линейное время.
