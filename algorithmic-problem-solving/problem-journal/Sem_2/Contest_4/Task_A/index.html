Семестр 2 · Контест 4

Задача A — Кратчайшие пути в графе

Accepted · C++ · 2 августа 2026

Алгоритм Дейкстры с индексируемой двоичной кучей: одна запись на вершину и обновление оценки через DecreaseKey.

Результат

Статус

Accepted. Для разреженного неориентированного графа использована Дейкстра с собственной индексируемой min-heap.

  • время: \(O((n+m)\log n)\) на тест;
  • память: \(O(n+m)\);
  • операция обновления оценки: DecreaseKey.

Условие

Расстояния от одной вершины

Дан взвешенный неориентированный граф с неотрицательными весами и стартовая вершина \(s\). Для каждой вершины \(v\) нужно найти длину кратчайшего пути из \(s\). Для недостижимых вершин выводится предусмотренное условием значение бесконечности.

Каждое ребро \(\{u,v\}\) хранится в списках смежности дважды: как \(u\to v\) и \(v\to u\).

Ключевая идея

Почему работает Дейкстра

d[v] — длина лучшего уже найденного пути. На каждом шаге извлекается нераскрытая вершина с минимальным d[v]. Из-за неотрицательности весов путь через остальные нераскрытые вершины уже не сможет улучшить это расстояние, поэтому оно становится окончательным.

Условие \(w(e)\ge 0\) существенно: при отрицательных рёбрах более короткий путь к раскрытой вершине мог бы обнаружиться позднее.

Структура данных

Индексируемая min-heap

Для каждой ещё не раскрытой вершины куча хранит пару \((d[v],v)\).

  • HeapItem::value — текущая оценка d[v];
  • HeapItem::query_id — номер вершины;
  • position_[v] — позиция её единственного элемента в массиве кучи.

position_ находит элемент за \(O(1)\), после чего DecreaseKey восстанавливает порядок за \(O(\log n)\). Повторный Insert при релаксации здесь недопустим.

Корректность состояния

Два инварианта кучи

Перед каждой итерацией:

\[ \neg expanded[v]\quad\Longleftrightarrow\quad v\text{ находится в куче}. \]

Поэтому проверка !expanded[to] гарантирует, что перед DecreaseKey значение position_[to] не равно -1.

Кроме того, ключ каждой находящейся в куче вершины равен её текущему d[v]. При улучшении вычисляется

\[ \Delta=d_{old}[v]-d_{new}[v]>0, \qquad d_{old}[v]-\Delta=d_{new}[v]. \]

Основная операция

Релаксация

long long new_dist = d[v] + e.c;
if (!expanded[e.to] && new_dist < d[e.to]) {
  long long delta = d[e.to] - new_dist;
  d[e.to] = new_dist;
  heap.DecreaseKey(e.to, delta);
}

delta нужно вычислить до присваивания нового расстояния. Все вершины заранее добавляются в кучу, иначе первая попытка улучшить отсутствующую вершину обратилась бы к position_[v] == -1.

Доказательство

Окончательность извлечённой оценки

Каждое конечное d[v] является длиной конкретного пути: начальное d[s] = 0 соответствует пустому пути, а релаксация лишь добавляет одно ребро.

Предположим, что вершина \(v\) извлечена с оценкой больше истинного расстояния. На кратчайшем пути к ней возьмём первую нераскрытую вершину \(x\). Её предшественник уже раскрыт, значит ребро к \(x\) было релаксировано и \(d[x]=\delta(s,x)\le\delta(s,v)<d[v]\). Это противоречит минимальности извлечённого ключа.

Реализация

Принятый код

#include <cstdint>
#include <iostream>
#include <vector>

namespace Detail {
struct HeapItem { std::int64_t value; int query_id; };

class MinHeap {
 public:
  explicit MinHeap(int n) : position_(n, -1) {}
  int Size() const { return static_cast<int>(buffer_.size()); }
  void Insert(std::int64_t value, int id) {
    int pos = Size();
    buffer_.push_back({value, id});
    position_[id] = pos;
    SiftUp(pos);
  }
  HeapItem ExtractMin() {
    HeapItem result = buffer_[0];
    int last = Size() - 1;
    if (last == 0) {
      buffer_.pop_back();
      position_[result.query_id] = -1;
      return result;
    }
    SwapItems(0, last);
    buffer_.pop_back();
    position_[result.query_id] = -1;
    SiftDown(0);
    return result;
  }
  void DecreaseKey(int id, std::int64_t delta) {
    int pos = position_[id];
    buffer_[pos].value -= delta;
    SiftUp(pos);
  }

 private:
  static int Parent(int v) { return (v - 1) / 2; }
  static int Left(int v) { return 2 * v + 1; }
  static int Right(int v) { return 2 * v + 2; }
  static bool Less(const HeapItem& a, const HeapItem& b) {
    return a.value != b.value ? a.value < b.value : a.query_id < b.query_id;
  }
  void SwapItems(int a, int b) {
    HeapItem tmp = buffer_[a]; buffer_[a] = buffer_[b]; buffer_[b] = tmp;
    position_[buffer_[a].query_id] = a;
    position_[buffer_[b].query_id] = b;
  }
  void SiftUp(int v) {
    while (v > 0 && Less(buffer_[v], buffer_[Parent(v)])) {
      int p = Parent(v); SwapItems(v, p); v = p;
    }
  }
  void SiftDown(int v) {
    while (true) {
      int best = v, left = Left(v), right = Right(v);
      if (left < Size() && Less(buffer_[left], buffer_[best])) best = left;
      if (right < Size() && Less(buffer_[right], buffer_[best])) best = right;
      if (best == v) return;
      SwapItems(v, best); v = best;
    }
  }
  std::vector<HeapItem> buffer_;
  std::vector<int> position_;
};
}  // namespace Detail

struct Edge { int to; long long cost; };
const long long cInfinity = 2009000999;

void Solution() {
  int n, m;
  std::cin >> n >> m;
  std::vector<std::vector<Edge>> graph(n);
  for (int i = 0; i < m; ++i) {
    int u, v, c;
    std::cin >> u >> v >> c;
    graph[u].push_back({v, c});
    graph[v].push_back({u, c});
  }
  int s;
  std::cin >> s;
  std::vector<bool> expanded(n, false);
  std::vector<long long> d(n, cInfinity);
  d[s] = 0;
  Detail::MinHeap heap(n);
  for (int v = 0; v < n; ++v) heap.Insert(d[v], v);
  for (int i = 0; i < n; ++i) {
    auto [dist, v] = heap.ExtractMin();
    expanded[v] = true;
    for (const Edge& e : graph[v]) {
      long long new_dist = d[v] + e.cost;
      if (!expanded[e.to] && new_dist < d[e.to]) {
        long long delta = d[e.to] - new_dist;
        d[e.to] = new_dist;
        heap.DecreaseKey(e.to, delta);
      }
    }
  }
  for (long long dist : d) std::cout << dist << ' ';
  std::cout << '\n';
}

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);
  int t;
  std::cin >> t;
  while (t-- > 0) Solution();
}

Оценка

Сложность

Последовательная вставка и извлечение \(n\) вершин требуют \(O(n\log n)\). Все списки смежности просматриваются за \(O(m)\), а успешные релаксации дают не более \(O(m\log n)\).

\[ T=O((n+m)\log n),\qquad M=O(n+m). \]

Отладка

Типичные ошибки

  • перепутать ключ и идентификатор в Insert;
  • добавить только стартовую вершину, хотя DecreaseKey требует существующий элемент;
  • уменьшать ключ уже раскрытой вершины с позицией -1;
  • не обновить обе записи position_ после обмена;
  • использовать Дейкстру при отрицательных весах;
  • выбрать слишком маленький INF или узкий тип расстояния.

Паттерн

Как распознать метод

Одна стартовая вершина, взвешенный граф и неотрицательные веса ведут к Дейкстре. Для одинаковых весов достаточно BFS, для весов 0 и 1 — 0-1 BFS, а отрицательные рёбра требуют другого алгоритма, например Bellman–Ford.

В индексируемой куче value = d[v], query_id = v, а position_[v] указывает на единственный элемент вершины.
