Семестр 2 · Контест 3

Задача E — Мосты

Accepted · C++ · 2 августа 2026

Low-link value показывает, может ли DFS-поддерево вернуться к родителю или выше без родительского ребра; отсутствие такого пути точно характеризует мост.

Результат

Статус

Accepted. Использован DFS-лес с временами входа, low-link values и сохранением исходных номеров рёбер.

  • время: \(\Theta(n+m)\);
  • память: \(\Theta(n+m)\);
  • кратные рёбра корректно различаются по edge_id.

Условие

Найти номера всех мостов

Дан неориентированный граф

\[ G=(V,E), \qquad V=\{1,2,\ldots,n\}, \qquad E=\{e_1,e_2,\ldots,e_m\}. \]

Рёбра пронумерованы в порядке ввода. Ребро \(e\) называется мостом, если после его удаления число компонент связности увеличивается:

\[ c(G-e)>c(G). \]

Граф может быть несвязным, поэтому DFS строит лес, а не одно дерево.

Теория

Мост и цикл

Для любого ребра неориентированного графа

\[ \boxed{e\text{ — мост}\iff e\text{ не лежит ни в одном цикле}}. \]

Если ребро лежит на цикле, оставшаяся часть цикла даёт обходной путь между его концами. Обратно, если после удаления ребра концы остаются связаны, обходной путь вместе с удалённым ребром образует цикл.

Неудачный подход

Почему нельзя удалять рёбра по одному

Для каждого ребра можно временно удалить его и проверить связность DFS или BFS. Но один обход требует \(\Theta(n+m)\), поэтому суммарно получится

\[ \Theta\bigl(m(n+m)\bigr). \]

Нужен один DFS, который одновременно выясняет наличие альтернативного пути для каждого поддерева.

Наблюдение

Альтернативный выход из поддерева

Пусть \(\{v,to\}\) — ребро дерева DFS, где \(v\) является родителем. После удаления ребра поддерево \(to\) отделится тогда и только тогда, когда из него нет другого ребра в \(v\) или любого строгого предка \(v\).

Поэтому достаточно хранить минимальное время входа предка, достижимого из поддерева без использования родительского ребра.

Состояние DFS

enter и ret

Время входа

При первом посещении вершины:

enter[v] = ret[v] = timer++;

Для предка \(p\) и потомка \(x\) выполняется \(enter[p]<enter[x]\).

Low-link value

ret[v] — минимальное время входа вершины, достижимой после спуска внутри DFS-поддерева \(v\) и не более одного недревесного ребра вверх.

После обработки ребёнка:

ret[v] = std::min(ret[v], ret[to]);

Для ребра в уже посещённую вершину:

ret[v] = std::min(ret[v], enter[to]);

Здесь используется именно enter[to]: текущее ребро непосредственно ведёт в to, а ret[to] описывает другие пути чужого поддерева.

Критерий

Строгое неравенство

Для ребра дерева DFS

\[ \boxed{ \{v,to\}\text{ — мост} \iff ret[to]>enter[v] }. \]

При равенстве из поддерева есть альтернативное ребро обратно в \(v\), значит ребро лежит на цикле. При меньшем значении достигается строгий предок. Только строгое превышение означает отсутствие любого обходного пути.

Кратные рёбра

Почему нужен номер ребра

В списке смежности хранится пара {to, edge_id}, а DFS пропускает только конкретное родительское ребро:

if (id == edge_id) {
  continue;
}

Два параллельных ребра между вершинами не являются мостами: после удаления одного остаётся второе. Если пропустить все рёбра по условию to == parent, альтернативное ребро потеряется и ответ станет неверным.

Доказательство

Корректность критерия

После завершения dfs(to) значение ret[to] учитывает все обратные рёбра из поддерева. Если оно не превосходит enter[v], существует альтернативный путь из поддерева к \(v\) или выше; вместе с древесным ребром он образует цикл.

Если \(ret[to]>enter[v]\), ни одна вершина поддерева не достигает \(v\) или его предков без ребра \(\{v,to\}\). Его удаление отделяет всё поддерево, поэтому ребро является мостом.

Реализация

Accepted-код

#include <algorithm>
#include <functional>
#include <iostream>
#include <utility>
#include <vector>

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);

  int n;
  int m;
  std::cin >> n >> m;

  std::vector<std::vector<std::pair<int, int>>> adj(n + 1);
  for (int i = 0; i < m; ++i) {
    int u;
    int v;
    std::cin >> u >> v;
    adj[u].push_back({v, i});
    adj[v].push_back({u, i});
  }

  std::vector<int> enter(n + 1, -1);
  std::vector<int> ret(n + 1, 0);
  std::vector<bool> is_bridge(m, false);

  int timer = 0;
  int count_bridges = 0;

  std::function<void(int, int)> dfs = [&](int v, int edge_id) {
    enter[v] = ret[v] = timer++;

    for (auto [to, id] : adj[v]) {
      if (id == edge_id) {
        continue;
      }

      if (enter[to] == -1) {
        dfs(to, id);
        ret[v] = std::min(ret[v], ret[to]);

        if (ret[to] > enter[v]) {
          ++count_bridges;
          is_bridge[id] = true;
        }
      } else {
        ret[v] = std::min(ret[v], enter[to]);
      }
    }
  };

  for (int v = 1; v <= n; ++v) {
    if (enter[v] == -1) {
      dfs(v, -1);
    }
  }

  std::cout << count_bridges << '\n';
  for (int i = 0; i < m; ++i) {
    if (is_bridge[i]) {
      std::cout << i + 1 << '\n';
    }
  }
}

Оценка

Сложность

Каждая вершина открывается один раз, каждое неориентированное ребро просматривается по одному разу с каждого конца, а действия на ребре занимают \(O(1)\):

\[ \boxed{T(n,m)=\Theta(n+m)}. \]

Списки смежности, массивы и рекурсивный стек занимают

\[ \boxed{W(n,m)=\Theta(n+m)}. \]

Проверки

Граничные случаи

  • граф без рёбер не содержит мостов;
  • каждое ребро дерева-пути является мостом;
  • рёбра простого цикла мостами не являются;
  • в несвязном графе внешний цикл обрабатывает каждую компоненту;
  • два параллельных ребра дают альтернативный путь;
  • петля обновляет ret[v] значением enter[v] и мостом не является.

Разбор ошибок

Типичные ошибки

  1. Пропуск родительской вершины вместо ребра. Это ломает обработку кратных рёбер.
  2. Нестрогое условие. При \(ret[to]=enter[v]\) есть альтернативное ребро; нужен знак >.
  3. Проверка до завершения ребёнка. Значение ret[to] ещё не учитывает всё поддерево.
  4. Не поднять ret[to]. Тогда обратное ребро из глубины не повлияет на предков.
  5. Использовать ret[to] для посещённого соседа. Недревесное ребро ведёт непосредственно в to, поэтому нужен enter[to].
  6. Запустить DFS только из вершины 1. Мосты в других компонентах будут пропущены.
  7. Потерять номера рёбер. Ответ и различение параллельных рёбер требуют edge_id.
  8. Перепутать нумерацию. Внутренний индекс начинается с нуля, вывод — с единицы.

Надёжность

Глубина рекурсии

На графе-пути глубина рекурсивного DFS равна \(\Theta(n)\). При больших ограничениях это может переполнить системный стек. Итеративному варианту нужен явный стек и отдельная фаза выхода, в которой вычисляются ret и критерий моста.

В финальном коде явно подключён <algorithm> для std::min.

Перенос идеи

Как распознать low-link

  • дан неориентированный граф;
  • удаление ребра может разрушить связность;
  • ответ зависит от существования обходного пути;
  • для DFS-поддерева важно достижение предка без родительского ребра;
  • ограничения требуют линейного алгоритма.
\[ \text{удаление ребра} \Longrightarrow \text{обходной путь} \Longrightarrow \text{обратное ребро из поддерева} \Longrightarrow \min enter \Longrightarrow \text{low-link}. \]

Вывод

Главный итог

Один DFS вычисляет для каждого поддерева минимальное время входа, достижимое через альтернативное ребро. Для древесного ребра

\[ \boxed{ret[to]>enter[v]} \]

ровно тогда, когда поддерево \(to\) не имеет другого выхода к \(v\) или выше. Сохранение edge_id является частью корректности, а не только технической деталью.
