Семестр 2 · Контест 3

Задача A — Поиск цикла в ориентированном графе

Accepted · C++ · 31 июля 2026

Серые вершины кодируют текущий путь DFS: ребро в серую вершину замыкает цикл, а массив родителей восстанавливает его вершины.

Результат

Статус

Accepted. Использован DFS с тремя цветами и восстановлением найденного цикла по массиву родителей.

  • время: \(\Theta(n+m)\);
  • память: \(\Theta(n+m)\);
  • граф может содержать петли, кратные рёбра и несколько компонент.

Условие

Ориентированный цикл

Дан ориентированный граф

\[ G=(V,E), \qquad V=\{1,2,\ldots,n\}, \qquad |E|=m, \]

где \(1\le n\le5\cdot10^5\) и \(0\le m\le5\cdot10^5\). Нужно определить наличие ориентированного цикла и при его существовании вывести вершины любого цикла в порядке обхода.

Начальная вершина повторно в конце не выводится. Петля \((v,v)\) считается циклом из одной вершины.

Ограничения

Почему нужен один полный обход

Отдельный поиск из каждой вершины может потребовать

\[ O\bigl(n(n+m)\bigr), \]

поэтому нужен алгоритм, обрабатывающий каждую вершину и каждое ребро постоянное число раз. DFS даёт \(O(n+m)\), но одного флага visited недостаточно: ребро в уже полностью обработанную вершину не обязательно образует цикл.

Наблюдение

Ребро в текущий стек DFS

Серые вершины образуют текущий путь рекурсивного DFS:

\[ v_0\to v_1\to\cdots\to v_t. \]

Если из \(v_t\) существует ребро в серую вершину \(v_i\), то древесный путь

\[ v_i\to v_{i+1}\to\cdots\to v_t \]

вместе с ребром \(v_t\to v_i\) образует ориентированный цикл.

Цикл обнаруживается ровно в момент рассмотрения ребра в вершину, которая всё ещё находится в текущем стеке DFS.

Состояния

Три цвета вершин

  • 0, белая — DFS ещё не входил в вершину;
  • 1, серая — вершина находится в текущем стеке;
  • 2, чёрная — вершина и все её исходящие рёбра полностью обработаны.
\[ 0\longrightarrow1\longrightarrow2. \]

Каждая вершина запускает рекурсивную обработку не более одного раза.

Инвариант

Что поддерживает DFS

  1. серые вершины — в точности текущий стек вызовов;
  2. они лежат на одном пути дерева DFS;
  3. parent[x] хранит предыдущую вершину этого пути;
  4. у чёрных вершин просмотрены все исходящие рёбра;
  5. при ребре \(v\to u\) в серую вершину цепочка родителей ведёт от \(v\) к \(u\).

Алгоритм

Обработка вершины

  1. Покрасить \(v\) в серый.
  2. Для каждого ребра \(v\to u\):
    • если \(u\) белая, записать parent[u] = v и запустить DFS;
    • если \(u\) серая, сохранить начало и конец цикла;
    • если \(u\) чёрная, пропустить ребро.
  3. Если цикл не найден, покрасить \(v\) в чёрный.

Внешний цикл запускает DFS из каждой белой вершины, чтобы охватить все компоненты. После первого найденного цикла поиск немедленно завершается.

Важное различие

Ребро в чёрную вершину не доказывает цикл

В графе

\[ 1\to2, \qquad 1\to3, \qquad 3\to2 \]

вершина \(2\) может быть полностью обработана до ребра \(3\to2\), хотя цикла нет. Поэтому проверка любого посещённого соседа ошибочна; нужен именно цвет 1.

Восстановление

Цепочка родителей

Пусть найдено ребро

\[ \texttt{cycle\_end}\to\texttt{cycle\_start}, \]

где cycle_start — серая вершина. По указателям родителей строится цепочка

\[ \texttt{cycle\_end} \to \operatorname{parent}[\texttt{cycle\_end}] \to\cdots\to \texttt{cycle\_start}. \]

Она записана от потомка к предку, поэтому после reverse получаем вершины от начала к концу древесного пути. Найденное обратное ребро замыкает этот список. Начальную вершину второй раз добавлять не нужно.

Пример

Цикл внутри пути DFS

Для рёбер

\[ 1\to2, \qquad 2\to3, \qquad 3\to4, \qquad 4\to2 \]

DFS строит путь \(1\to2\to3\to4\). Ребро \(4\to2\) ведёт в серую вершину, поэтому после разворота цепочки родителей выводится цикл

\[ 2, 3, 4. \]

Доказательство

Корректность алгоритма

Если найдено ребро в серую вершину

Серая вершина является предком текущей в дереве DFS. Древесный путь от неё до текущей вершины вместе с найденным ребром образует ориентированный цикл. Массив родителей перечисляет этот путь в правильном порядке после разворота.

Если в графе существует цикл

Рассмотрим первую вершину цикла, в которую входит DFS. Пока обход идёт по рёбрам цикла, вершины на текущем пути остаются серыми. Рано или поздно будет рассмотрено ребро, ведущее в уже серую вершину этого цикла, и алгоритм обнаружит его.

Итог

При выводе YES восстановлен корректный цикл. Если ни одного ребра в серую вершину не найдено, ориентированного цикла в графе нет, и NO корректен.

Реализация

Accepted-код

#include <functional>
#include <iostream>
#include <vector>

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);

  int n;
  int m;
  std::cin >> n >> m;

  std::vector<std::vector<int>> adj(n + 1);
  for (int i = 0; i < m; ++i) {
    int u;
    int v;
    std::cin >> u >> v;
    adj[u].push_back(v);
  }

  std::vector<int> color(n + 1, 0);
  std::vector<int> parent(n + 1, -1);
  int cycle_start = -1;
  int cycle_end = -1;

  std::function<bool(int)> dfs = [&](int v) -> bool {
    color[v] = 1;

    for (int u : adj[v]) {
      if (color[u] == 0) {
        parent[u] = v;
        if (dfs(u)) {
          return true;
        }
      }

      if (color[u] == 1) {
        cycle_start = u;
        cycle_end = v;
        return true;
      }
    }

    color[v] = 2;
    return false;
  };

  for (int v = 1; v <= n && cycle_start == -1; ++v) {
    if (color[v] == 0) {
      dfs(v);
    }
  }

  if (cycle_start == -1) {
    std::cout << "NO";
    return 0;
  }

  std::vector<int> cycle;
  int cur = cycle_end;

  while (cur != cycle_start) {
    cycle.push_back(cur);
    cur = parent[cur];
  }

  cycle.push_back(cycle_start);
  reverse(cycle.begin(), cycle.end());

  std::cout << "YES\n";
  for (int v : cycle) {
    std::cout << v << ' ';
  }
}

Оценка

Сложность

Каждая вершина посещается не более одного раза, а каждый список смежности просматривается не более одного раза. Восстановление проходит по циклу длины не более \(n\):

\[ \boxed{T(n,m)=\Theta(n+m)}. \]

Списки смежности, цвета, родители, найденный цикл и рекурсивный стек занимают

\[ \boxed{W(n,m)=\Theta(n+m)}. \]

Проверки

Граничные случаи

  • граф без рёбер приводит к ответу NO;
  • внешний цикл находит цикл в любой компоненте;
  • петля восстанавливается как цикл из одной вершины;
  • кратные рёбра не нарушают алгоритм;
  • ребро к чёрной вершине пропускается;
  • восстановление останавливается в cycle_start, а не в корне дерева DFS.

Разбор ошибок

Типичные ошибки

  1. Только visited. Булев массив не различает текущий путь и завершённые ветви.
  2. Любое ребро в посещённую вершину считается обратным. Цикл гарантирует только ребро в серую вершину.
  3. Нет родителей. Три цвета обнаруживают цикл, но без parent не восстанавливают путь.
  4. DFS продолжается после находки. Дальнейший обход может перезаписать границы цикла; результат нужно немедленно передавать вверх.
  5. Путь восстанавливается до корня. Вершины выше cycle_start не входят в найденный цикл.
  6. Запуск только из вершины 1. Цикл может лежать в другой компоненте.
  7. Правило неориентированного графа. Ребро из потомка в родителя здесь действительно замыкает ориентированный цикл и не должно пропускаться.

Технические детали

Переносимость и глубина рекурсии

Принятый листинг использует reverse без явного подключения <algorithm>. Переносимый вариант должен добавить этот заголовок и вызвать std::reverse.

В худшем случае глубина рекурсивного DFS равна \(\Theta(n)\). При \(n=5\cdot10^5\) это чувствительно к размеру системного стека. В другом окружении надёжнее итеративный DFS с явным стеком и позицией следующего ребра.

Перенос идеи

Как распознать паттерн

  • дан ориентированный граф;
  • нужно найти и вывести конкретный цикл;
  • ограничения требуют линейного времени;
  • граф может быть несвязным.
\[ \text{текущий стек DFS} \Longleftrightarrow \text{серые вершины}, \]
\[ \text{ребро в серую вершину} \Longleftrightarrow \text{ориентированный цикл}, \]
\[ \texttt{parent} \Longleftrightarrow \text{восстановление пути}. \]

Вывод

Главный итог

Для ориентированного графа нужно знать не только факт посещения, но и завершена ли обработка вершины:

\[ \text{белая}\to\text{серая}\to\text{чёрная}. \]

Серые вершины образуют текущий путь DFS. Ребро в серую вершину замыкает этот путь, а массив родителей восстанавливает один цикл за линейное время.
