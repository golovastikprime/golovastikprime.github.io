Семестр 2 · Контест 3

Задача F — Точки сочленения

Accepted · C++ · 2 августа 2026

Low-link value определяет, какие дочерние поддеревья потеряют связь с верхней частью DFS-дерева после удаления вершины.

Результат

Статус

Accepted. Использован DFS-лес с временами входа, low-link values и отдельными критериями для корня и некорневой вершины.

  • время: \(\Theta(n+m)\);
  • память: \(\Theta(n+m)\);
  • петли и кратные рёбра поддерживаются через edge_id.

Условие

Разделяющие вершины

Дан неориентированный граф \(G=(V,E)\), где \(V=\{1,2,\ldots,n\}\),

\[ 1\le n\le2\cdot10^4, \qquad 1\le m\le2\cdot10^5. \]

Разрешены петли и кратные рёбра. Нужно вывести в возрастающем порядке все вершины, удаление которых вместе с инцидентными рёбрами увеличивает число компонент связности:

\[ c(G-v)>c(G). \]

Неудачный подход

Почему нельзя проверять вершины по одной

Удаление каждой вершины с отдельным DFS или BFS требует

\[ \Theta\bigl(n(n+m)\bigr) \]

времени. Вместо этого один DFS должен определить, какие поддеревья способны связаться с верхней частью дерева без своего родителя.

Структура DFS

Дочерние поддеревья

Белый сосед становится ребёнком в DFS-дереве. Ребро в уже посещённую вершину, отличное от конкретного родительского ребра, создаёт дополнительную связь с предком.

Между поддеревьями разных детей одной вершины нет рёбер: если бы такое ребро существовало, DFS из первого поддерева перешёл бы в ещё белую вершину второго и объединил их в одно поддерево.

Состояние DFS

enter и ret

При входе в вершину:

enter[v] = ret[v] = timer++;

ret[v] — минимальное время входа вершины, достижимой после спуска внутри поддерева \(v\) и не более одного недревесного ребра вверх.

После обработки ребёнка информация поднимается:

ret[v] = std::min(ret[v], ret[to]);

Недревесное ребро непосредственно ведёт в to:

ret[v] = std::min(ret[v], enter[to]);

Критерий

Некорневая вершина

Пусть \(v\) не является корнем DFS-дерева. Тогда

\[ \boxed{ v\text{ — точка сочленения} \iff \exists\text{ ребёнок }to: ret[to]\ge enter[v] }. \]

Такое поддерево не достигает строгого предка \(v\) без самой вершины \(v\), поэтому после её удаления отделяется от верхней части.

Особый случай

Корень DFS-дерева

У корня нет верхней части, поэтому low-link критерий к нему неприменим:

\[ \boxed{ r\text{ — точка сочленения} \iff children(r)\ge2 }. \]

children — число рёбер DFS-дерева из корня, а не его степень в исходном графе. После удаления корня разные дочерние поддеревья не могут связаться между собой.

Важное различие

Почему знак нестрогий

При \(ret[to]=enter[v]\) поддерево возвращается только в саму \(v\), но не в её строгого предка. После удаления \(v\) эта связь исчезнет, поэтому вершина остаётся точкой сочленения.

  • мост \(\{v,to\}\): ret[to] > enter[v];
  • точка сочленения \(v\): ret[to] >= enter[v].

Кратные рёбра

Пропуск конкретного ребра

DFS получает номер родительского ребра и пропускает только его:

if (id == edge_id) {
  continue;
}

Параллельное ребро в ту же родительскую вершину должно остаться альтернативной связью и повлиять на ret. Поэтому сравнения только с вершиной-родителем недостаточно.

Доказательство

Корректность критериев

Для некорневой вершины ребёнок с \(ret[to]<enter[v]\) имеет путь в строгого предка, поэтому после удаления \(v\) остаётся связан с верхней частью. При \(ret[to]\ge enter[v]\) такого пути нет, и поддерево отделяется.

Для корня разные дети DFS образуют разные поддеревья без рёбер между ними. При двух детях удаление корня разделяет компоненту, при одном — все остальные вершины остаются в одном поддереве.

Реализация

Accepted-код

#include <algorithm>
#include <functional>
#include <iostream>
#include <utility>
#include <vector>

int main() {
  std::ios::sync_with_stdio(false);
  std::cin.tie(nullptr);

  int n;
  int m;
  std::cin >> n >> m;

  std::vector<std::vector<std::pair<int, int>>> adj(n + 1);
  for (int i = 0; i < m; ++i) {
    int u;
    int v;
    std::cin >> u >> v;
    adj[u].push_back({v, i});
    adj[v].push_back({u, i});
  }

  std::vector<int> enter(n + 1, -1);
  std::vector<int> ret(n + 1, 0);
  std::vector<bool> is_cut_point(n + 1, false);

  int timer = 0;
  int cut_points = 0;
  std::function<void(int, int)> dfs = [&](int v, int edge_id) {
    enter[v] = ret[v] = timer++;
    int children = 0;

    for (auto [to, id] : adj[v]) {
      if (id == edge_id) {
        continue;
      }

      if (enter[to] == -1) {
        ++children;
        dfs(to, id);
        ret[v] = std::min(ret[v], ret[to]);

        if (edge_id != -1 && ret[to] >= enter[v]) {
          is_cut_point[v] = true;
        }

        if (edge_id == -1 && children >= 2) {
          is_cut_point[v] = true;
        }
      } else {
        ret[v] = std::min(ret[v], enter[to]);
      }
    }
  };

  for (int v = 1; v <= n; ++v) {
    if (enter[v] == -1) {
      dfs(v, -1);
    }
  }

  for (int i = 1; i <= n; ++i) {
    if (is_cut_point[i]) {
      ++cut_points;
    }
  }

  std::cout << cut_points << '\n';
  for (int i = 1; i <= n; ++i) {
    if (is_cut_point[i]) {
      std::cout << i << ' ';
    }
  }
}

Оценка

Сложность

Каждая вершина открывается один раз, каждое неориентированное ребро рассматривается с обоих концов, а работа при просмотре ребра постоянна:

\[ \boxed{T(n,m)=\Theta(n+m)}. \]

Граф, массивы и рекурсивный стек занимают

\[ \boxed{W(n,m)=\Theta(n+m)}. \]

Проверки

Граничные случаи

  • изолированная вершина не является точкой сочленения;
  • корень с одним ребёнком не является точкой сочленения;
  • корень с двумя детьми является точкой сочленения;
  • внутренняя вершина пути является точкой сочленения;
  • вершины простого цикла не являются точками сочленения;
  • петли не увеличивают число детей и не меняют ответ;
  • кратные рёбра корректно учитываются по номеру ребра.

Разбор ошибок

Типичные ошибки

  1. Применить критерий некорневой вершины к корню. Корень проверяется только по числу детей DFS.
  2. Считать соседей вместо детей. children увеличивается лишь перед рекурсией в белую вершину.
  3. Использовать строгий знак. Равенство тоже отделяет поддерево после удаления вершины; нужен >=.
  4. Проверять до завершения ребёнка. ret[to] ещё не учитывает всё поддерево.
  5. Не поднять ret[to]. Связь из глубины не достигнет предка.
  6. Использовать ret[to] для посещённого соседа. Нужно enter[to].
  7. Запустить DFS только из вершины 1. Остальные компоненты будут пропущены.
  8. Несколько раз посчитать одну вершину. Булев массив и финальный подсчёт устраняют дублирование.
  9. Пропускать родительскую вершину. При кратных рёбрах нужно пропускать конкретный edge_id.

Надёжность

Глубина рекурсии

На графе-пути глубина равна \(\Theta(n)\). Принятое решение прошло проверку при \(n\le2\cdot10^4\), но в среде с малым стеком можно использовать итеративный DFS с позицией следующего ребра и отдельной фазой выхода.

В финальном коде явно подключены <algorithm> и <utility>.

Перенос идеи

Как распознать low-link

  • дан неориентированный граф;
  • удаление вершины может разрушить связность;
  • важно понять, какие DFS-поддеревья отделятся;
  • достаточно знать самого раннего достижимого предка;
  • ограничения требуют линейного алгоритма.
\[ \text{удаление вершины} \Longrightarrow \text{отделившиеся поддеревья} \Longrightarrow \text{связь со строгим предком} \Longrightarrow \min enter \Longrightarrow \text{low-link}. \]

Вывод

Главный итог

Для некорневой вершины:

\[ v\text{ — точка сочленения} \iff \exists\,to: ret[to]\ge enter[v]. \]

Для корня:

\[ v\text{ — точка сочленения} \iff children(v)\ge2. \]

Раздельная обработка корня и нестрогий знак — две принципиальные детали корректности.
